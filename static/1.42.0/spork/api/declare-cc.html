declare-cc

date ev-utils

The declare-cc module provides a DSL to the cc module for compiling C and C++ projects that eliminates boilerplate, provides incremental builds, and re-implements support for building project.janet projects outside of JPM.

(create-buffer-c bytes dest name)

Inline raw byte file as a c file. The header file will contain two exported symbols, `(string name "_emded")`, a
 pointer of an array of unsigned char, and `(string name "_embed_size")`, a size_t of the number bytes.
declare-cc/declare-archive function source 
(declare-archive &named entry name deps)

Build a janet archive. This is a file that bundles together many janet scripts into a janet image. This file can the be moved to any machine with a janet vm and the required dependencies and run there.

Declare a generic file to be installed as an executable.
declare-cc/declare-binscript function source 
(declare-binscript &named main name hardcode-syspath is-janet)

Declare a janet file to be installed as an executable script. Creates
a shim on windows. If hardcode is true, will insert code into the script
such that it will run correctly even when JANET_PATH is changed. if auto-shebang
is truthy, will also automatically insert a correct shebang line.

Mark a file as general documentation to be installed. Documentation will be installed to $SYSYPATH/man/`prefix`/`(basename source)`

Declare a janet file to be the entry of a standalone executable program. The entry file is evaluated and a main function is looked for in the entry file. This function is marshalled into bytecode which is then embedded in a final executable for distribution.

Declare headers for a library installation. Installed headers can be used by other native libraries.

Declare a native module. This is a shared library that can be loaded dynamically by a janet runtime. This also builds a static libary that can be used to bundle janet code and native into a single executable.
declare-cc/declare-project function source 
(declare-project &named name description url version repo tag dependencies author license)

Define your project metadata. This should
be the first declaration in a project.janet file.
Sets up the JPM-style build rule system as well as
creates a number of default bundle hooks including:
- build
- clean
- check
- install
- list-rules
- rule-tree
declare-cc/declare-source function source 
(declare-source &named source prefix)

Create Janet modules. This does not actually build the module(s), but registers them for packaging and installation. :source should be an array of files and directores to copy into JANET_MODPATH or JANET_PATH. :prefix can optionally be given to modify the destination path to be (string JANET_PATH prefix source).
